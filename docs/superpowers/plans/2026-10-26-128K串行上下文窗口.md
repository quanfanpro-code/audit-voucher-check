# audit-voucher-check 128K 串行上下文窗口 Implementation Plan

> **For agentic workers:** 默认读取 `executing-plans.md`，串行逐项执行。只有用户另行授权开发阶段使用子 Agent 时才读取 `subagent-driven-development.md`；128K 抽凭窗口不得并行。所有步骤使用复选框跟踪，当前仅编写计划，不执行。

**Goal:** 在不改变凭证范围、证据、五项检查、专业结论和 Excel 底稿的前提下，增加 1M／128K 分流及单张凭证串行独立窗口调度。

**Architecture:** 原技能内一次分流；1M 走原流程。128K 由新增 PowerShell 调度脚本管理单张占用、任务包哈希、保存回执、恢复和主控轮换，指定清单、原始资料和已保存工作簿仍是唯一业务真相。OCR 不在本工程范围内。

**Tech Stack:** Windows、Windows 自带 PowerShell、既有 Markdown／JSON／Excel 模板、Microsoft Excel 实际验收；不新增 Python 包、OCR、外部模型 API 或后台进程。

**Spec:** `docs/superpowers/specs/2026-10-26-128K串行上下文窗口-design.md`；需求见 `docs/requirements/2026-10-26-128K串行上下文窗口-requirement.md`。

## Global Constraints

- 不修改判断边界、底稿填写规则、规范性文件、空白 Excel 模板或既有专业判断；不减少指定凭证、附件、关联记录或检查程序。
- 1M 不创建或读取调度文件；128K 使用当前同一个模型的前台串行窗口，上一张未保存并解除占用不得开始下一张。
- 修改任何既有文件前，按宿主规则备份到 `C:\Users\27651\BackUp\项目名_年月日_时分秒\` 并做字节比较；运行时覆盖调度状态也同样备份。
- PowerShell 每次执行先设置 `$OutputEncoding = [Console]::OutputEncoding = [Text.Encoding]::UTF8`；新建中文文本使用 UTF-8 with BOM。
- 原始凭证、附件和源模板只读；测试只使用虚构资料和临时副本，不上传客户资料。
- 基线模板或校验脚本存在既有不一致时先报告并停止，不顺带改模板或把旧失败改写为通过。
- 不执行 Git 提交、推送、分支清理或依赖安装，除非用户届时另行明确授权。

[IO.File]::WriteAllText($task, ($packetObject | ConvertTo-Json -Depth 6), [Text.UTF8Encoding]::new($true))

& $dispatcher -Action 初始化 -Root $root -Mode 1M -ModelBinding current-model -BackupRoot $backup
if (Test-Path (Join-Path $root '.上下文调度\上下文调度状态.json')) { throw '1M不应创建调度状态' }

if (-not $rejected) { throw '活动凭证未解除时第二凭证不得开始' }

继续在校验脚本写入完整的 19 次循环；每次使用不同虚构凭证键和结果副本，不读取真实 Excel：
```powershell
for ($index = 2; $index -le 20; $index++) {
    $key = '测试账套|2026|01|记|{0:D4}' -f $index
    $roundTask = Join-Path $root ('单张凭证任务_' + $index + '.json')
    $packetObject.voucher_key = $key
    [IO.File]::WriteAllText($roundTask, ($packetObject | ConvertTo-Json -Depth 6), [Text.UTF8Encoding]::new($true))
    $roundBook = Join-Path $root ('结果_' + $index + '.xlsx')
    Copy-Item -LiteralPath $workbook -Destination $roundBook
    & $dispatcher -Action 开始 -Root $root -Mode 128K -ModelBinding current-model -BackupRoot $backup -TaskId $key -TaskPacket $roundTask -WindowId ('window-' + $index)
    & $dispatcher -Action 完成 -Root $root -Mode 128K -ModelBinding current-model -BackupRoot $backup -TaskId $key -ResultWorkbook $roundBook -SavedAndReadBack
}
$state = & $dispatcher -Action 状态 -Root $root -Mode 128K -ModelBinding current-model -BackupRoot $backup | ConvertFrom-Json
if (-not $state.rotation_required) { throw '完成20次调度后必须轮换主控窗口' }
Write-Output '通过：主控窗口轮换'
```
