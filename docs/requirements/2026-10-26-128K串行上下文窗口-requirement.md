# audit-voucher-check：128K 串行上下文窗口需求

- 日期：2026-10-26
- 状态：用户已于 2026-10-26 确认；并授权自主完成后续设计文档，实际编码前停止
- 范围：仅上下文装载、独立窗口调度与断点交接
- 本轮工作边界：完成需求、方案设计和实施计划文档后，在实际编码前停止；不进入编码、测试执行或交付改动

## 背景与问题

本技能现有功能可正常工作，但在 128K 上下文模型上，逐张凭证的账簿、附件、图片、规范条文和判断过程持续累积，可能超出上下文。用户要求只降低上下文占用，任何功能、判断、证据和成果均不得因此降级。

## 已确认的用户决定

1. 将“只降低上下文占用，功能和结果绝不降级”作为硬门槛。
2. 技能入口询问本次使用 1M 还是 128K 上下文模型；1M 保持现有执行流程，128K 才进入新增的优化调度路径。
3. 128K 路径可以使用独立对话或独立 Agent 窗口，但必须串行，任何时候只运行一个模型任务。
4. 不借助并行提速，不更换当前模型。
5. 用户已撤回先前关于 OCR 路线选择的补充要求，本次不纳入任何 OCR 改动。

## 功能范围

- 在现有技能中增加轻量上下文分流，不建立另一套抽凭规则或简化底稿流程。
- 128K 路径以单张凭证的完整检查为独立窗口边界，串行处理指定清单。
- 每个窗口取得该张凭证按现有规则需要的完整账簿、附件、关联记录和适用条文，执行同样的五项检查及必要追加程序。
- 每张检查后仍写入并保存同一主体工作簿；下一张从可靠保存点和证据索引继续，不在新窗口背负此前凭证的原始内容。
- 主控窗口只保留指定清单、实际保存进度、下一张完整凭证号和待解决的具体状态。
- 复核旧结论仍优先利用已有底稿，只有具体歧义才定点回看原始资料。

## 明确不做

- 不减少指定凭证、附件页码、关联分录、原始证据或适用规范。
- 不改变五项检查、适用性判断、问题门槛、未决事项、修订历史或专业结论。
- 不把 OCR 成功、字段提取或附件清单当作完成凭证检查。
- 不减少工作表、字段、双向链接、格式、着色、公式或最终 Excel 验收。
- 不更换模型，不新增 OCR 或其他外部模型服务，不并行检查凭证。
- 不因独立窗口而把不同主体混入同一工作簿。

## 约束与失败处理

- 独立窗口必须使用当前对话所用的同一模型；宿主不能保证时，不静默换成其他模型。
- 任一时刻最多检查一张凭证；上一张未可靠保存前不得开始下一张。
- 每个窗口只能声明实际读取和实际执行的程序，不能从主控摘要推断凭证已经检查。
- 单张凭证所需完整证据在当前 128K 环境中无法装入时，停止并报告，不通过少看附件或减少检查硬跑。
- 保存失败、凭证号冲突、资料版本变化或进度无法确认时停止，不继续写后续凭证。
- 未通过等价验收的环节不得纳入可用的 128K 路径。

## 验收标准

1. **路由**：入口能区分 1M 与 128K；1M 不进入新调度，128K 不进入并行调用。
2. **串行与保存**：执行记录证明同一时刻最多检查一张凭证，保存并回读成功后才进入下一张。
3. **检查等价**：同一凭证在两种路径下读取的证据范围、适用规范、执行程序和比较双方一致，没有以上下文为由漏页或减少检查。
4. **成果等价**：相同事实和证据下，五项结果、整张结论、问题及未决事项、修订历史、总表统计和底稿内容不得下降；仅上下文调度记录可以不同。
5. **实际模型验收**：在同一 128K 模型上对代表性凭证完成整批检查，逐张比较事实、结论和证据位置；存在未解释差异时不得发布。
6. **上下文目标**：代表性批量任务不再因前面凭证的图片、附件文字和判断过程累积超限；新窗口不会把历史摘要当作已执行检查。
7. **原功能回归**：现有验收用例、模板检查和 Excel 实际验收全部通过；1M 除新增的入口询问外，业务行为不变。
8. **失败不降级**：单张资料过大、模型不一致、状态损坏或窗口无法隔离时，明确停止，不自动减少资料或程序。

## 调研摘要

- `SKILL.md` 已要求一次建立索引、复用证据、查完一张保存一张，并记录最后完成与下一张完整凭证号。
- 本技能没有 `scripts/` 执行器，实际读取、判断和写底稿主要由 Agent 按说明完成，因此独立窗口的完整任务交接和保存门禁是本项目的重点。
- 现有工作簿和证据索引是续作依据；主控摘要只能用于调度，不能替代单张凭证的事实与判断过程。

## 设计阶段已解决事项

- 宿主支持时前台串行调用当前模型的独立 Agent；不能保证同模型时改用同模型手工独立对话，无法隔离则停止 128K 路径。
- 调度状态只记录窗口和工作簿锚点；实际完成范围与下一张仍由指定清单和已保存底稿确定，不另造业务结论。
- 等价验证逐张比较证据范围、五项结果、结论、问题、修订和链接，并实际打开 Excel 验收；存在未解释差异则不开放 128K 路径。
