# 独立复核记录

复核日期：2026-09-23。

范围：技能正文、判断边界、底稿字段、计划模板、验收用例、技能元数据及空白 Excel。复核关注具体判断、证据限制、凭证标识、逐张保存、已有底稿重判和各处结论的一致性。

## 方法

一名独立代理审查全部文件与要求的对应关系；另一名未接收预期答案的代理，对六项合成情景执行判读，修正后再测试两项新情景。主执行者核对发现、修订文件并用桌面 Excel 验证模板。此处“独立”指不同代理分别执行，不表示项目注册会计师已签署复核意见。

## 发现与关闭

| 发现 | 已实施的修正 | 复核结果 |
| --- | --- | --- |
| 同项存在已确认错误与未知子项时，旧字段规则可能统一写未能核实 | 保留已确认的不符／不正确等结果，另列未决子项，同步整张限制与汇总 | 独立复查及新增情景均确认两者同时保留 |
| 页签改名不会更新HYPERLINK文字目标 | 明确重建链接目标，并测试两张不同凭证的导航 | Excel可分别定位到对应页签 |
| 重判时可能只改整张结论，留下旧程序标签 | 旧、新单项结果记入历史，当前程序行、整张结论及汇总一起更正 | 规则一致性复查通过 |
| 复制已填页可能残留前张证据、历史和签署 | 优先复制干净模板；列清全部复位字段，跨页取值保持绝对引用 | 两张凭证引用及限制不串用 |
| 旧结果标签可被手输进下拉字段 | 加入停止型错误提示，并在程序验证中检查实际输入有效性 | 旧“发现异常”标签不能通过有效性检查；程序写入仍须主动验证 |
| 凭证号输入与输出的格式要求不同 | 原号输入按文本；汇总公式保持常规格式，由公式返回原号文本 | 在Excel复制并重写引用后显示实际凭证号，不显示公式字符串 |
| 公开包含机器路径及项目特征金额 | 移除个人路径，将教学金额换成保持关系的独立合成数值 | 公开文件检查通过，未包含公司原始资料 |

## 行为判读结果

八项情景覆盖：无发票预付款、暂借款错列费用、有效追加审批、早于合同最晚日期实际完成交付、已证实的销售代付、明确金额多记、同项明确错误与税务资格未知并存，以及仅有可靠账簿及附件但没有记账凭证影像。

结果能够区分：无票与不齐、审批金额变化与账证差异、最晚交付日与实际交付日、户名事实差异与会计错报，以及已确认错误与尚未判明子项。没有为了统一结果而把所有凭证判为正常或异常。

其中一项初测只提供价税总额，没有提供税额及抵扣依据，测试执行者仅对该税额子项提出定点核验，没有重新要求已核实的付款、审批或期间资料。这保留了实际证据边界，没有以减少未知数量为目的强行判通过。

## 模板与发布验证

`scripts/校验底稿模板.ps1` 在 Windows 桌面 Excel 中通过16项检查，覆盖实际打开、空白与零、旧标签拦截、已确认错误和限制同时汇总、第二张独立引用、两张页签导航、插行后引用，以及测试不改变源模板。

模板修订前后逐单元格比较，原有事实空值及26个公式的内容未改动；改动限于下拉设置及必要的输入／公式格式。测试数据留在内存中，模板不含业务数据或人工签署。

技术检查不能保证任意未来执行者永不误判。后续实务仍须逐张填写实际比较双方、依据和限制；结论必须接受证据与项目复核的检验。本记录也不表示重新审计了任何真实项目。
