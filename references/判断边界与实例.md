# 五项检查的判断边界

## 使用顺序

先确定分录处于什么业务阶段，再判断每项需要证明什么。读现有支持证据及相反证据，核对关联分录、结算关系和替代依据，最后形成结论。不能从“附件不符合想象中的清单”直接跳到“业务不真实”。

以下数值均为判断边界的教学情景，不能引用为任何项目的已查事实。执行中的事实、完整凭证号及出处必须来自当次资料。

## 1. 原始凭证是否齐全

这里的“齐全”指足以支持本笔分录所需关键事实和金额的业务凭据，并非“合同、发票、验收单、回单全部都有”。应以业务阶段和明确适用要求判断必要性。资料支持本次检查，仍不等于独立证明所有外部真实性。

写“不齐”必须同时记录：

1. 缺少的具体必要凭据或关键业务依据。
2. 为什么对本笔分录及当前业务阶段必要，依据来自哪里。
3. 在哪批实际提供的资料、哪些文件／页码中核查过。
4. 已有其他资料证明了什么，为什么仍不能替代缺少的那项。
5. 影响哪一个具体判断，其他判断是否仍可完成。

**可以判断不齐的情景**：计入差旅费 7,200 元，现有一张说明用途为“出差备用金”的转款回单；检查了本笔全部附件和后续核销记录后，无行程、报销结算或其他实际支出依据。回单能证明借款付出，不能单独支持已发生 7,200 元费用。准确写“本笔费用确认缺少实际支出及核销依据”，不能只写“没发票”。是否还存在错计费用，应结合借款与入账证据另判。

**不能据此判不齐的情景**：合同约定付 30% 预付款，支付证据与合同主体、金额和进度一致，账挂预付款，尚未交货开票。不能因未有发票或验收单认定该预付业务原始凭证不齐。

刻章等小额支出没有发票时，应看收据、订单、审批、交付和付款等已有资料是否支持实际支出及金额。税前扣除／进项税问题按适用税法及实际税务处理另查，不能由税票缺失推断业务不存在。

**银行付款的必要凭据**：财政部《会计基础工作规范》第四十八条要求支付款项的原始凭证有收款证明。对账载银行付款，核对银行回单、银行流水、收款方收款证明或其他能可靠证明本笔实际收付的凭据；不拘泥于“必须是银行回单”。同时区分本张后附、明确归档并可追溯关联本张、以及为审计另查的共用资料。共用流水能证明付款，不自动变成本张后附原始凭证：如果本张未附、也未归档关联付款证明，原始凭证项写**本张付款支持不齐**，但付款事实可另据流水核实。已检查本笔附件及可用共用银行资料后仍均无付款证明，也写具体不齐及查找范围，不能用“无法判断”掩盖缺项。若付款证明已归档并可追溯关联本张，按实际证明力判断齐全性，不机械要求纸面装订。以上均不直接证明业务虚假或款项错记。税款缴款书等官方缴款证明若能证明该笔已缴，应按其证明力判断。依据：[财政部令第98号公布的《会计基础工作规范》第四十八条](https://www.mof.gov.cn/gp/xxgkml/tfs/201903/t20190318_3195239.htm)。

**购买实物的验收证明**：同条还要求购买实物的原始凭证有验收证明。对已将设备、材料等购入实物确认为资产或费用的凭证，查签收、入库、验收或其他能证明收货验收的记录。已经查明没有的，写“原始凭证不齐”，具体说明物品、入账阶段和查找范围；不能只写“到货待核”。采购人自述到货、物流信息或送货单能否起到验收证明作用，应看其实际签认内容，不机械要求另一种固定表式。预付款尚未进入交付确认阶段，不因没有验收证明判不齐。缺验收证明不能直接推出实物未到或账面金额错误，交付时点无法确定时只限制确认期间等相应判断。

“原件”也不是纸质原件的代名词。电子凭证按其实际形态核查；扫描件是否足以支持特定判断，应结合来源和其他证据说明，不一律要求纸质原件。

只有序时账而未提供记账凭证影像，不等于业务原始凭据缺失。账载记录与附件可以照实核对并形成相应判断；仅票面记载、签章及标注附件数的检查受限。凭证注明的“附件张数”、电子文件数、PDF页数是不同计数口径，先核对实际单据覆盖，不能直接相减判缺件。

## 2. 记账凭证与原始凭证是否相符

检查双方必须在同一主体、同一业务、同一阶段及可比金额口径上。每个“不符”至少列出：账载记录及出处、原始资料及出处、比较字段、双方具体值、口径转换和仍未解释的差额。

| 情景 | 应怎样判断 |
| --- | --- |
| 账载银行支出 5,200，实际付款证据 5,000，核对无手续费、合并支付等解释 | 账载支付与原始支付证据相差 200，属于账证金额不符；进一步确定错账及调整依据。 |
| 借款 5,000，报销 4,970.00，退款 30.00 均已入账 | 三者勾稽为 5,000，无未解释金额差。不能把报销与借款差 30.00 判不符。 |
| 账、发票、实际支付均 612.00，最初审批 600.00 | 账证金额相符；审批金额相差 12.00，核对有无有效追加审批以及制度要求。未查明不能直接判越权，更不能列为账票不符。 |
| 付款申请初值 18,140.00，账载 18,150.00，原单备注后来列明 18,150.00 | 核查备注性质、时间和效力，区分原申请和最终结算。不能截取旧值直接认定不符。 |
| 发票价税总额 2,260，账载成本 2,000、税额 260 | 复算合计相等，价税分拆不是差错；税额可否抵扣另判。 |
| 总合同 100,000，本次预付 30,000，后续尾款 70,000 | 比较合同进度与本次付款阶段，不能拿本次付款直接减合同总价后认定差错。 |

审批单、合同、发票之间不同，要明确究竟是哪两份资料不一致。只有账载内容与支持该记录的原始资料冲突，才归入本项“不符”。存在争议或不同口径但尚未查清的，记录具体差异及待判断事项。

## 3. 账务处理是否正确

按业务实质逐项判断确认、分类、计量及税务处理。写“不正确”须说明实际分录、应有处理、适用依据及决定性事实；建议分录和金额能确定才列，不能用整张检查金额替代错报额。

公司政策没找到时，已有适用准则与事实能支持的部分正常下结论。确实依赖未明政策或关键事实的事项，限定到该事项；不能把所有设备、费用或研发支出统一写“政策未提供，无法判断”。

设备总价 1,130,000，已取得发票 791,000，并不能单靠未开票差额 339,000 认定资产多计。分别核查合同、交付、达到可使用状态、暂估与结算依据；进项税金额及抵扣条件另行核查。暂估成本合理与税额可抵扣是两个判断。

对科目名称不同但核算实质可能相同的情形，查科目核算内容及报表归类；不要仅因偏好另一科目就判错。

## 4. 是否记录于恰当的会计期间

并排列出实际业务／服务期间、交付或可使用时点、开票日、付款日、记账日和关联计提／冲回分录。确定本笔是在确认费用／资产，还是支付以前确认的负债。

| 已知情况 | 证据能支持的结论边界 |
| --- | --- |
| 二月服务三月付款，二月已计提，三月冲应付 | 付款跨月不等于费用跨期。 |
| 二月已完成服务，三月首次记费用，二月相关账簿确认未计提且不存在其他合理处理 | 可认定费用确认月份与业务归属不一致。继续区分月度归属差异、报表期间影响和重要性，不把年内跨月一概说成年报错报。 |
| 合同要求六月二十五日前交付，六月十日入账 | “最晚交付日”不能证明六月十日尚未实际交付。查实际履约事实后再判。 |
| 支付一年服务费，当月全部计费 | 查已履行服务的性质、期间、现有摊销政策和重要性依据。证据支持未来期间受益且无适用简化理由时，再量化应分摊差异；不能看到一年字样直接推算错报。 |
| 费用单日期去年、本年核销备用金 | 查去年是否已确认，核销与确认不能混为一谈。 |
| 同月先发生费用后补借款或结算 | 先后顺序可作为流程检查线索，不能据此自动判错期。 |

重要性不是删除已确认差异的理由。已确认的具体差异照实记录，是否建议调整、对报表何期间有影响分别说明。未取得重要性依据不能自行设门槛消除差异。

## 5. 回款单位与销售客户名称是否一致

仅适用于销售回款。以实际银行收款户名／汇款人信息，与对应合同、销售记录的客户全称比较。

- 名称一致：确认实际比对的两方及出处，不进一步声称收入确认、交易真实性都已通过。
- 名称不同：如实写“不一致”，并说明代付、集团结算、平台收单、保理等现有解释及证据。有证据支持合理关系时保留名称差异事实，整张不自动判问题。
- 缺少汇款方信息：本项“未能核实—未见本笔实际汇款人信息”；其他金额、账务或期间检查继续。
- 采购付款、借款支付、摊销、计提：本项“不适用”，写明业务类型。收款供应商与付款对象的核对另设程序。

平台名称与商户名称不同，应核对平台订单、发票、结算角色及交易对应关系，不能只按名称不相等推断虚假交易。

## 6. “未能核实”和“明确问题”怎样使用

“未能核实”只用于对结论必要的具体事项，而该事项在实际查阅、比较和可行替代核验后仍证据不足。必须说明已经确定的部分和仍缺的决定性事实。不能把未执行、未搜索、工具未打开，改写成企业未提供；不能以任意新增要求制造证据不足。

限制只涉及已约定检查目标所需的关键事实。资料形式不理想、可选程序未做或不影响当前判断的信息未取得，应记在实际覆盖说明中，不据此将整张改成“尚有具体事项未能判断”。资料已充分支持某项判断时，应明确下结论，不为规避判断继续叠加与本笔无关的查验、制度或补件条件。

同项中已确认的差异或错误不能被另一子项的未知抹去。例如已查明数量多记、但税额抵扣条件尚未核实，账务处理项仍保留已证实的不正确事实，另列税额限制；不得只剩一个“未能核实”。

特别是付款凭据已经确认缺少时，原始凭证项应写“不齐”；只有付款对象、实际付款金额或会计处理中的某个决定性事实在尽合理核查后仍不明，才把**那个子项**写为未能核实，并说明何种证据可解决。整张结论首先呈现已经查明的问题，不用“尚有具体事项未能判断”掩盖它。

若本张付款附件不齐，但另查银行流水已证实金额和收款方，写“本张付款支持不齐；另查流水已核实付款金额和收款方”。付款事实不再写“未能核实”；账证金额、账务处理等项目仍独立判断。若只有合同或审批单，且查不到任何付款证明，写明已核对的资料范围，不虚构付款已发生。

写“明确问题”须同时有：**可指明的适用标准／约定／制度要求，且可靠现有证据证明实际不符合**。区分会计差错、授权／流程偏离、其他明确事项。单纯提出一种更好的处理建议不算证明错误。

已看到相反证据时必须处理：例如初始申请与最终批准不同、账簿备注解释过差额、重复发票是分次付款而非重复费用。不能省略这些事实以维持初始结论。

发票查验未实施只能写未实施；查验接口失败只说明未取得验证结果；不能写已查验通过、假票或业务不存在。未提供审批制度不证明无权审批，见到签字也不证明已核实权限。

## 7. 整张结论及统计

| 当前结论 | 使用条件 |
| --- | --- |
| 未执行 | 尚无实际检查。 |
| 检查中 | 本轮计划内尚有能实施而未做完的检查。 |
| 所执行检查未发现具体问题 | 适用项目已实施，证据支持相应判断，无未解决具体事项。不能用于抹去证据限制。 |
| 尚有具体事项未能判断 | 现有资料检查已做完，存在影响本张结论的具体限制／尚未解释事项，尚不能证明违反标准。写清事项，保留其他已核实结果。 |
| 发现明确问题 | 至少一项满足明确标准与可靠反证，列性质和依据。 |
| 发现明确问题，另有事项未能判断 | 明确问题与具体限制并存，两者都呈现。 |

程序是否完成、业务检查结果、项目组是否复核是三个不同维度。“现有资料检查已完成”不代表“所有认定已证实”，也不代表“复核完成”。

问题张数按存在明确问题的凭证去重，未能判断张数另计，同一张可以出现在两个维度；总表的互斥当前结论类别合计才应等于指定清单张数。重复资料、事项条数、受检金额、差异金额不能混算。

“异常误差”是审计抽样中的特定概念，不能作为“看起来不寻常”的标签。本技能默认检查指定项目，不提供从指定清单推断整个总体的统计结论。

如果项目实际采用准则意义上的审计抽样并需评价总体，另行按批准的抽样设计执行。不能把本技能对指定凭证的分类直接当成抽样评价规则：对无法实施设计程序或适当替代程序的样本，第1314号第20条对其作为控制偏差或细节测试错报的处理另有规定。底稿应同时区分“已观察到的具体事实”和“抽样评价时的处理”，由项目注册会计师评价，不能虚构已经查明某个事实错误。
