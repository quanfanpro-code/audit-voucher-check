# Excel 底稿字段与填写规则

## 一、交付结构

必交文件为已填写的 `<项目名>_抽凭检查底稿.xlsx`。空白模板只是表式，不能作为已执行抽凭的交付成果。

模板有五个工作表：`逐张抽凭记录`、`五项标准复核`、`单张凭证底稿`、`事项跟进`、`填写规则`。正式使用时将单张模板复制成每张凭证一页，按真实凭证号命名；空白模板页可保留并明确标示，不计入已查凭证。

用户已有确认表式时保留其结构和必要字段，用本规则补足信息，不为了套模板改排整份旧底稿。单项“当前结果”和整张“当前结论”以逐张明细为唯一正式记录，总表及五项汇总引用这些字段，不另做一套人工结论。

## 二、标识、链接和状态

1. 所有表均保留主体／账套和完整原始凭证号。说明问题时直接用该号。事项可用“完整凭证号／事项1”区分，证据可用本张内的 E1 等索引；这些不是凭证替代编号。
2. Excel 页签超过长度限制或存在非法字符时使用能辨认的简称，表内完整原号和总表对应关系不截断。不同主体同号时必须区分，不能静默覆写。
3. 可点击内部链接到具体明细，证据路径连向持久原文件或经授权保存的副本。必须保留路径和页码文本，即使链接功能失效仍可定位。不得指向会被清理的临时 OCR 图片作为唯一证据。
4. 执行状态：`未开始`、`检查中`、`现有资料检查已完成`。项目组复核单独记录实际签署状态，不因 AI 自检完成自动写复核完成。
5. 当前结论：`未执行`、`检查中`、`所执行检查未发现具体问题`、`尚有具体事项未能判断`、`发现明确问题`、`发现明确问题，另有事项未能判断`。定义见判断边界文件。
6. 五项检查分别使用：
   - 原始凭证：`齐全／不齐／未能核实／不适用／未执行`。
   - 账证比较：`相符／不符／未能核实／不适用／未执行`。
   - 账务处理：`正确／不正确／未能核实／不适用／未执行`。
   - 期间归属：`恰当／不恰当／未能核实／不适用／未执行`。
   - 回款户名：`一致／不一致／未能核实／不适用／未执行`。
7. 同项存在不同结果时，先分清具体子项。已证实“不齐／不符／不正确／不恰当／不一致”且另有子项未能核实的，主结果保留已证实的负面／差异结果，在紧邻说明及整张限制栏同时写明未决子项；汇总必须同时显示该结果和限制。没有已证实负面／差异、但决定本项结论的事实仍不明时才用“未能核实”，并注明其余已核实部分。必要时增加子行。整张结论仍按问题性质判断，户名不同不自动变成明确问题。
8. 未知金额留空并解释；不得填 0 代替未知。金额、日期用 Excel 数值／日期类型，凭证号及账号按文本保存。

## 三、逐张抽凭记录

一张凭证一行。字段如下：

| 字段 | 填写要求 |
| --- | --- |
| 主体／账套、完整凭证号、记账日期 | 从账簿／凭证取值，遇冲突列明来源 |
| 业务及本笔阶段 | 简明说明预付、费用确认、付款、核销、计提等 |
| 受检金额、币种及单位 | 说明是借方额、贷方额、交易额还是选中科目金额，不能借贷相加 |
| 检查范围 | 全凭证还是部分项目，关联账簿行和附件范围 |
| 执行状态、当前结论 | 引用本张明细，未查不预填通过 |
| 结论依据、未解决具体事项 | 明确问题和限制不能藏在长文中或旧版本里 |
| 明细链接 | 到本张明细的真实页签 |
| 实际执行者、完成日期时间 | 如为 AI，填实际工具名称和实际时间 |
| 项目组复核 | 仅实际人员完成后据实填写 |
| 凭证及账簿位置 | 可直接查到原票面或所用序时账；没见票面则说明 |

汇总张数以主体／账套和完整凭证号去重。受检金额跨凭证合计前说明是否存在预付、结算、尾款对同一业务重复覆盖；不能把覆盖金额称为不同交易的净额。

## 四、五项标准复核

一张凭证一行，列主体／账套、完整凭证号、五项结果、当前结论、具体限制和明细链接。结果引用对应明细，不手工抄出另一套分类。

需要统计时，各项“未执行”“不适用”“未能核实”分开；“不一致”户名事实不能不经分析就并入错报张数。当前结论总数应与指定清单一致，已确认问题事项条数与问题凭证张数分别说明。

## 五、单张凭证底稿

### A. 基本信息

主体／账套、完整原始凭证号、日期、业务阶段、摘要、受检金额与口径、币种单位、检查范围、账簿及票面位置、适用会计框架及依据来源、已读文件／页码与未读部分。

### B. 分录记录

每行记录原分录行次、日期、摘要、科目、明细核算、借方金额、贷方金额、币种、交易对方、源表单元格／凭证页码。源行号不是自编凭证号。分录多于空行时扩行，不能只留总数。

借贷平衡检查仅适用于完整且未被生成表重复展开的分录；只选一部分时说明不能据此检查全凭证平衡。

### C. 证据索引

本张内索引、证据种类、原文件完整路径、页码／表名及单元格、实际看到的关键事实／数值及证明用途。压缩包保留容器及内部路径。重复引用写首次核实位置及本次用途；未读取资料明确写未读取及原因。

### D. 检查过程

| 字段 | 最低内容 |
| --- | --- |
| 检查项目／具体判断 | 五项基本检查，必要时拆成具体子项及追加程序 |
| 是否适用 | 适用或不适用，并在说明中写原因 |
| 比较标准及出处 | 合同条款、有效制度、适用会计依据或明确核对标准 |
| 账载对象／实际值 | 所核对的分录、主体、日期、金额、数量及出处 |
| 原始对象／实际值 | 对应原始资料的实际内容，不能只写文件名 |
| 证据位置 | 比较双方具体页码／单元格，或可直接回查的索引 |
| 实际动作及复算 | 实施什么比较、如何勾稽，金额组成及算式 |
| 单项结果 | 五项各自的结果口径，未执行不写通过 |
| 差异／解释／未能核实的具体事项 | 不符写差在哪；不齐写必要依据缺什么；限制只落到具体事项 |

**记录示例，仅示意字段填法：**“账载借款 5,000.00；报销单逐项合计 4,970.00；退款回单 30.00；相关核销分录与三者对应。复算 4,970.00＋30.00＝5,000.00，无未解释差额。本项相符。实际证据位置另据所读资料填写。”正式底稿不能复制示例金额或用示例代替实际读取。

### E. 事项事实与影响

事项、具体事实、适用标准及不符合之处、事项性质、受检金额、差异金额、建议调整金额、证据位置、跟进状态及口径说明。

事项性质：`会计差错`、`授权／流程偏离`、`其他明确问题`、`待解释差异`、`具体证据限制`。仅存在不同值尚未证明错误时用待解释差异；不能直接写会计差错。

三个金额字段分别说明含义。无法量化的空白金额配文字原因；同一问题在不同凭证出现时标明关联，避免重复累计。调账建议须有确定依据，AI 不替企业入账。

### F. 当前结论及签署

当前结论、执行状态、结论及事实依据、尚未解决的具体事项、调整及期间影响、实际执行者、实际完成时间、续作位置、项目组编制人、项目组复核人及复核日期／范围。

首次结论和首次日期另存。当前结论是本张唯一权威当前值，不覆盖历史。

### G. 结论修订记录

逐次追加实际时间、执行者、原结论、新结论、修改原因、所依据证据／原底稿位置。必要回看原始资料的，注明回看对象及结果；仅按已有事实纠正误判时如实说明，不虚构新证据。单项结果被纠正时，修订历史也应指出具体项目及旧、新结果，随后更新实际过程区的当前结果；不要只改整张结论而留下冲突的单项标签。

## 六、事项跟进

按需要登记实际存在的事项，不生成每张一行的“待补资料”占位清单。字段：主体、完整凭证号、事项、具体事实、标准／必要依据、性质、受检金额、差异金额、拟调整金额、证据位置、当前状态、已执行及下一步。

跟进状态：`未解决`、`已解释`、`已纠正`、`仅记录限制`。收到资料不等于已解决；保留实际追加检查和判断。事项跟进汇集逐张明细的同一事项，不独立更改性质或结论。

## 七、空白模板的定位与扩展

下列位置仅用于随技能附带的空白模板。执行中插行或沿用其他表式后，以字段标题和实际位置重新定位；不得盲写旧坐标。

| 区域 | 空白模板位置 |
| --- | --- |
| 总表和五项表 | 第5行为字段，第6行为首张引用行 |
| 单张基本信息 | A4:C14为标签，D4:L14为输入区，每行一项 |
| 完整凭证号、日期、受检金额 | D5、D6、D9 |
| 分录 | 第18行为表头，第19至24行为预留区 |
| 证据 | 第27行为表头，第28至33行为预留区 |
| 五项过程 | 第36行为表头，第37至41行为五项，第42行起按需追加 |
| 五项结果 | K37至K41；单项不适用原因等写L列 |
| 事项 | 第45行为表头，第46至49行为预留区 |
| 当前结论、执行状态 | D52、D53 |
| 结论依据、未解决事项 | D54、D55 |
| 执行者、完成时间 | D57、D58 |
| 人工编制及复核 | D60至D62 |
| 初次结论、日期 | D63、D64 |
| 修订历史 | 第67行为表头，第68至72行为预留区 |

模板的总表、五项汇总首行以公式引用单张模板，完整凭证号为空时保持空白；不把空白模板计为一张。五项下拉与文字口径一致。模板不提供自动专业判定，填写者根据实际证据选择结果。

新项目先复制整份模板，保留一页干净表式供新增凭证使用；优先从该干净页复制。将明细页重命名为真实凭证号后，核对总表引用及链接。注意：普通公式的工作表引用可随 Excel 原生重命名更新，但 HYPERLINK 中以文字写入的页签名称不会自动更新，必须重建文字目标。若由其他表格工具插行或改名，还须确认其是否实际调整公式引用，不假定与 Excel 相同。

每新增凭证增加对应汇总行，并将普通公式和链接均指向新页。若不得不从已填明细复制，必须清除前张全部业务输入、证据路径、事项、五项结果、当前和初次结论、日期、修订历史及人工签署，状态恢复未执行／未开始；不能只改凭证号。汇总跨页取值使用绝对单元格引用，例如 `='真实页签'!$D$52`，复制行后只改页签映射，避免行号偏移。扩行不限制条数，增加后检查后续区块、公式、下拉和链接。

每张完成即保存当前工作簿，并回读本张及对应汇总。发生内容更新先按用户规则备份校验。所有原始账簿和附件只读，不能为让模板公式通过而改源数据。

## 八、验收记录

在填写规则页的项目验收区记录：实际清单数及逐张数、已检查范围、未完成事项、汇总与明细核对结果、保存及 Excel 实际打开情况、关键链接结果、长文本可读性、验收人和实际时间。空白模板的空验收栏不得预填通过。

链接目标必须在最终交付目录环境实测；不能用 XML 字符串是否包含某种标签代替可解析性核验。Excel 不能实际打开时说明失败对象及测试方式，不将某个已修改文件的失败推断成原文件本来就有错。
