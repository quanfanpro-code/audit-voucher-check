# 抽凭检查计划与流程

使用说明：执行者按实际资料填写下面各项，删除本行及方括号提示。本文是计划模板，不是已获批准的项目计划，也不是已实施程序记录。

主体／账套：[全称]。期间：[期间]。计划版本及日期：[据实填写]。用户要求：[具体检查目的]。

本次检查：[指定清单或已批准选样方法]，共[实际数量]张。清单使用完整原始凭证号，附账簿定位、目录和入选原因。检查其他关联凭证只用于解释业务链，不擅自扩大已检查张数。

## 2. 资料与输出

序时账：[路径、表名、行范围、字段和生成口径]。

凭证附件：[授权根目录及涵盖的子目录]。

已有底稿：[路径及版本；没有则写无]。

## 3. 当前盘点与尚未检查部分

记录实际文件数、凭证数、已读和未读范围、重复及特殊格式。盘点不表示已实质检查。共用政策、制度及银行资料以实际找到的内容为准；对未知事项不写已取得或企业未提供。

## 4. 具体检查标准

| 检查项 | 比较对象和所需业务事实 | 不适用条件 |
| --- | --- | --- |
| 原始凭证是否齐全 | 本笔分录所需关键业务及金额依据，结合已有替代证据 | 依实际业务说明；不能仅因无发票判不齐 |
| 记账凭证与原始凭证是否相符 | 同事项、同阶段的账载值与原始资料值，解释价税、预付、退款等 | 依具体事项判断 |
| 账务处理是否正确 | 实际分录、业务实质与适用会计依据 | 依具体事项判断 |
| 是否记录于恰当会计期间 | 实际履约／服务期间及以前计提，与本笔入账期间 | 依具体事项判断 |
| 回款单位与销售客户名称是否一致 | 实际汇款人全称与对应销售客户全称 | 非销售回款不适用 |

本批需要增加的具体检查：[仅列与本批业务有关的程序、依据和比较对象]。

## 5. 执行及逐张留痕

建立索引 → 读取一张的分录与附件 → 确定业务阶段 → 实施适用比较／复算 → 记录证据及单项结果 → 形成当前结论 → 更新总表 → 保存回读 → 下一张。

已有底稿复核时先利用原记录，必要时定点回看原始资料。原结论、实际过程和修订理由保留。按完整凭证号报告进度。

原资料保持不变。写入已有成果前按用户规则备份并校验。同一工作簿串行写入，第一张验证保存与链接，以后仅检查新增记录和受影响部分。

## 6. 问题、限制与追加核验

不符要列比较双方、实际值和出处；不齐要列必要依据及现有替代证据为何不足；未能核实只限定具体事项。明确问题要有适用标准和可靠反证，区分会计与流程问题。

用户限定现有资料时，充分利用现有资料完成判断，剩余限制如实记录。仅确有影响且授权范围内无法解决的重要歧义集中询问，不自动向第三方发送资料请求。

## 7. 进度与验收

按[实际约定]报告已保存张数、主要具体事项和下一张。根据已完成凭证实际耗时估算剩余时间；未经实测不承诺固定每张耗时。

验收：清单与逐张记录一一对应；每项有过程、证据、结果；当前结论与汇总一致；金额及问题去重口径明确；公式、链接和最终 Excel 实际打开正常；长文本可读；人工作业和复核签署不代填。未完成部分明确列示。
