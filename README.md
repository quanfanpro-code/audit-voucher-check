# 会计凭证检查与抽凭底稿

`audit-voucher-check` 是供 AI 助手执行凭证检查和底稿复核的技能，附可编辑 Excel 空白底稿与 Markdown 计划模板。

## 做什么

按完整原始凭证号逐张检查、记录比较过程和证据，交付填写完整的 Excel 抽凭底稿。五项基本检查为原始凭证是否齐全、账证是否相符、账务处理是否正确、会计期间是否恰当，以及销售回款人与客户名称是否一致。

规则明确区分事实差异、会计差错、流程偏离和具体证据限制。无发票不自动等于资料不齐，日期不同不自动等于跨期，已经查明的问题不能被另一事项的未知覆盖。

## 使用

将本仓库完整放入 AI 工具识别的技能根目录，文件夹命名为 `audit-voucher-check`，使 `SKILL.md` 直接位于该文件夹第一层。支持读取标准技能目录的工具可自动发现；其他工具可直接读取 `SKILL.md` 及其引用文件。

可用请求：

> 使用 $audit-voucher-check，按已确认范围检查序时账和凭证附件，每完成一张即保存检查过程和结论，交付 Excel 抽凭底稿。

> 使用 $audit-voucher-check，按已有底稿事实重新下结论，必要时定点回看原件，保留修改记录。

新项目使用 `assets` 下的空白模板副本。已有确认表式时沿用其结构。输出路径、备份路径和资料读取范围由使用者指定，不需要沿用作者的机器配置。客户资料应保存在使用者授权的环境中，仓库内只有规则、合成教学情景和空白模板。

## 验证

已在 Windows 与 Microsoft Excel 环境中验证模板。安装桌面 Excel 后，可用 PowerShell 执行 `scripts\校验底稿模板.ps1`。脚本在内存中使用明确标记的虚构数据，不改源模板或项目资料。

该脚本核对文件、引用、下拉及扩展行为。会计结论仍须依据当次资料、适用准则及实际执行的程序形成，并由项目人员按职责复核。AI执行记录与人工签署分开。
